# Taller Práctico Intensivo: POO, Clases y Objetos en Java

**IDE:** IntelliJ IDEA
**Versión de Java:** 27

## Estructura del proyecto

```
TallerPOO/
├── src/
│   └── com/taller/poo/
│       ├── seccion1_modelos/
│       │   ├── Vehiculo.java
│       │   ├── Estudiante.java
│       │   └── CuentaBancaria.java
│       │
│       ├── seccion2_utiles/
│       │   └── ConversorMoneda.java
│       │
│       ├── seccion4_ejecucion/
│       │   └── Principal.java
│       │
│       ├── seccion5_reto/
│       │   └── SistemaGestionCuentas.java
│       │
│       └── seccion6_debugging/
│           ├── PruebaEstudiante.java
│           ├── GestorVehiculos.java
│           ├── CuentaBancariaError.java
│           └── VehiculoShadowing.java

```

| Paquete | Contenido |
|---|---|
| `com.taller.poo.seccion1_modelos` | Secciones 1 y 3: modelado de clases, atributos y constructores |
| `com.taller.poo.seccion2_utiles` | Sección 2: clase utilitaria con métodos estáticos |
| `com.taller.poo.seccion4_ejecucion` | Sección 4: instanciación de objetos y salida formateada |
| `com.taller.poo.seccion5_reto` | Sección 5: reto integrador de consola |
| `com.taller.poo.seccion6_debugging` | Sección 6: casos de estudio corregidos |

## Ejecución

1. Abre el proyecto en IntelliJ IDEA con el SDK de Java 27.
2. Ejecuta `Principal` o `SistemaGestionCuentas` con el icono verde junto a su método `main`.
